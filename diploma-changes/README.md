# Журнал змін дипломної роботи

Тут після **кожного сеансу** редагування `diploma.docx` з'являється окремий Markdown-файл,
у якому доступно описано, що саме було змінено. Так можна швидко переглянути історію правок,
не відкриваючи Word і не порівнюючи бінарні файли вручну.

## Як це працює
- Файли створює агент `diploma-writer` (через команду `/diploma`) автоматично в кінці сеансу.
- Один файл = один сеанс правок.
- Формат назви: `РРРР-ММ-ДД_ГГХХ-короткий-опис.md` (напр. `2026-06-05_1430-vstup-pravky.md`).
- Найновіші зміни — внизу списку файлів за датою.

## Як читати
Markdown відкривається будь-де: VS Code (з прев'ю), Obsidian, браузер, або просто як текст
у блокноті. Кожен запис містить:

- **Підсумок** — що зроблено одним абзацом.
- **Точкові зміни** — для кожної правки: де (розділ/абзац), **Було → Стало**, причина.
- **Доповнення** — нові вставлені фрагменти.
- **Плейсхолдери рисунків** — де лишено `[РИСУНОК …]` / `[ЗАМІНИТИ РИСУНОК …]`.
- **Рецензія** — короткий вердикт `diploma-reviewer`.
- **Не зачеплено** — підтвердження, що решта тексту незмінна (кількість абзаців до/після).

## Шаблон запису
Дивись `_TEMPLATE.md` у цій папці — за ним формується кожен новий файл.

## Важливо
- Це **журнал**, а не сам звіт. Редагувати ці файли вручну не треба — вони лише фіксують історію.
- Стан звіту ДО останнього сеансу завжди є у `diploma.backup.docx` (корінь проєкту) — для звірки в Word.
